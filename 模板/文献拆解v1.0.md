## 第一遍（5–10 分钟）：要不要读

| 五个问题 | 回答 |
| --- | --- |
| 类别：原创研究 / 综述 / 方法 / 理论？ | |
| 背景：建立在哪些前人工作上？ | |
| 正确性：假设看起来站得住吗？ | |
| 贡献：主要新发现是什么？ | |
| 清晰度：写得清楚吗？ | |
| **决定** | 停在这里 / 读第二遍 / 精读 |
