# C 级：实践者推崇的方法 · Tier C: practitioner favourites

<sub>C 级 = 来源主要是书籍、演讲、个人或组织经验，**缺乏对照研究**。它们可以提供思路和动力，但不能当作“已被证明有效”的结论。若某个方法的一部分有研究支持，会单独注明。</sub>

**一句话结论：** C 级方法最有价值的是**思考框架和执行纪律**；真正让知识留下来的，仍是 A 级的提取、间隔和反馈。

| 编号 | 方法 | 来源类型 | 有无对照研究 |
| --- | --- | --- | --- |
| [C1](#c1) | 多元思维模型（芒格） | 演讲、文集 | 无 |
| [C2](#c2) | 第一性原理 | 哲学传统、企业家访谈 | 无 |
| [C3](#c3) | 《原则》（达利欧） | 管理经验书 | 无 |
| [C4](#c4) | 超级学习者（Scott Young） | 个人项目与案例 | 无（书中原则多引自 A 级研究） |
| [C5](#c5) | 学习如何学习（Oakley） | 教材与慕课 | 课程整体无；内容多引自 A 级 |
| [C6](#c6) | 复盘 / AAR | 军事与组织实践 | **例外**：复盘/汇报有元分析 |

## C1 多元思维模型 · Latticework of mental models (Munger)

- **一句话：** 掌握多个学科的核心模型（如复利、激励、反馈回路、机会成本、概率），挂在一个“格栅”上，从多个角度分析同一问题。
- **原始出处：** Charlie Munger 1994 年在南加州大学商学院的演讲 [A Lesson on Elementary Worldly Wisdom](参考文献v1.0.md#munger1994)。
- **证据等级：C，缺乏对照研究。** 与 B5 组块理论和“迁移需要深层结构”的研究方向一致，但“多元模型使人决策更好”没有直接实验检验。
- **常见误传：** “背一张 100 个思维模型清单就够了”——芒格强调的是在真实问题中反复用。
- **操作步骤：** 为本领域挑 5–10 个“跨学科母模型”→ 每遇到一个新问题，写下至少两个模型的解释 → 记下哪个模型预测对了。
- **医学 / 科研用法：** 用“反馈回路”理解 p53–MDM2；用“基础概率”理解检验前概率；用“激励”理解发表偏倚。

<a id="c2"></a>

## C2 第一性原理 · First-principles thinking

- **一句话：** 把问题拆到最基本、确定成立的事实，再从这些事实重新推理，而不是照搬类比或惯例。
- **原始出处：** 概念可追溯到亚里士多德；现代流行版本来自 Elon Musk 等企业家，例如 2013 年 TED 访谈中谈到“从第一性原理而不是类比推理” [Musk 2013](参考文献v1.0.md#musk2013)。
- **证据等级：C，缺乏对照研究。**
- **常见误传：** “所有事都该从头推”——在医学中，大量知识来自经验证据而不是推导；从机制“推出”疗效正是许多失败药物试验的教训。第一性原理适合**发现假设**，不能替代临床证据。
- **操作步骤：** 写下问题 → 列出“我认为一定成立的前提”→ 逐个问“证据是什么？”→ 只用站得住的前提重建方案 → 用实验或文献检验。
- **医学 / 科研用法：** 课题设计时拆解“放疗为什么损伤肌肉”的基本环节，寻找未被检验的假设。

<a id="c3"></a>

## C3 《原则》· Principles (Dalio)

- **一句话：** 把经验教训写成可复用的原则，坚持“极度透明、极度求真”，用“痛苦 + 反思 = 进步”的循环处理失败。
- **原始出处：** [Dalio 2017《Principles》](参考文献v1.0.md#dalio2017)；[官方网站](参考文献v1.0.md#principles)。
- **证据等级：C，缺乏对照研究**（来源为个人和桥水公司的管理经验）。
- **常见误传：** 把一家对冲基金的管理文化直接搬到医院或实验室——其中“公开评价”等做法在不同组织文化中的效果未经检验。
- **可取的内核：** 把每次复盘的结论写成“下次遇到 X 就做 Y”的规则，形成个人原则库。
- **医学 / 科研用法：** 把投稿被拒、实验失败的教训写成“实验设计检查清单”。

<a id="c4"></a>

## C4 超级学习者 · Ultralearning (Scott Young)

- **一句话：** 用自主设计、高强度、目标导向的学习项目快速掌握技能；九条原则包括元学习、专注、直接实践、专项操练、提取、反馈、保持、直觉、实验。
- **原始出处：** [Young 2019《Ultralearning》](参考文献v1.0.md#young2019)。
- **证据等级：C，整套方法缺乏对照研究**；书中“提取”“反馈”“间隔保持”等原则本身引自 A 级研究。作者的个人项目（如自学 MIT 课程）是自我报告案例。
- **常见误传：** “一年自学完四年课程”是个案，不是可以期待的平均结果；高强度项目需要匹配个人时间，临床医生不必照搬。
- **可取的内核：** “直接实践”——尽可能在目标情境中练（要会读论文就直接读，要会写 R 就直接写分析）；“先做元学习”——开学前先花约 10% 的时间调研这门学问怎么学。
- **医学 / 科研用法：** 用 4–8 周为一个“学习项目”，以一份可交付成果（综述、复现分析、讲课）为终点。

<a id="c5"></a>

## C5 学习如何学习 · Learning How to Learn (Oakley)

- **一句话：** 一套面向大众的学习技巧课程：专注模式与发散模式交替、番茄钟对抗拖延、组块、提取和间隔。
- **原始出处：** [Oakley 2014《A Mind for Numbers》](参考文献v1.0.md#oakley2014)；Coursera 慕课 [Learning How to Learn](参考文献v1.0.md#oakleycourse)。
- **证据等级：C（课程整体缺乏对照研究）。** 其中提取、间隔、交错属 A 级；“专注/发散两种模式”是对神经科学研究的通俗类比，不应当作精确的脑科学结论；番茄钟作为时间管理工具缺乏高质量对照研究。
- **常见误传：** “发散模式”被说成大脑的一种已证实的生理状态——这是教学比喻。
- **可取的内核：** 用 25–50 分钟的专注块启动难任务；卡住时离开做别的，回来再提取。
- **医学 / 科研用法：** 夜班后碎片时间做闪卡；整块时间留给精读和写作。

<a id="c6"></a>

## C6 复盘 / AAR · After-action review

- **一句话：** 一件事结束后立刻回答四个问题：原本期望发生什么？实际发生了什么？为什么有差异？下次怎么做？
- **原始出处：** 美国陆军训练通令 [TC 25-20（1993）](参考文献v1.0.md#army1993)；中文“复盘”一词借自围棋，在中国企业管理中广泛使用。
- **证据等级：来源属 C，但这是本档的例外——复盘/汇报（debrief）有元分析支持。**
  - 事实：46 个样本的元分析显示，规范的复盘/汇报使团队和个人绩效比对照提高约 25%（d = 0.67），医疗与非医疗样本相近 [Tannenbaum & Cerasoli 2013](参考文献v1.0.md#tannenbaum2013)。
  - 事实：医学模拟教学中，汇报的具体形式（时长、是否用录像等）报告不完整，不同形式的比较结果不一致 [Cheng 2014](参考文献v1.0.md#cheng2014)。
- **常见误传：** “复盘就是总结经验”——有效复盘要对照**事先设定的目标**，并落到具体改进行为；“复盘是追责”——AAR 原则要求聚焦事件而不是个人。
- **操作步骤：** 见 [复盘表模板](../模板/复盘表v1.0.md)。
- **医学 / 科研用法：** 抢救后团队汇报；每个学习周期结束时复盘“哪种方法让我真正记住了”。
