# 扩充指南 · How to add a method

<sub>新增或修订方法时遵守本页。最后一节是可以直接粘贴给 Codex 的中文提示词。</sub>

## 条目格式（每条方法必须包含）

```markdown
<a id="a12"></a>

## A12 方法中文名 · English name

- **一句话：** 用一句话说清它是什么、怎么做。
- **原始出处：** 最早提出者与文献，链接到参考文献页中对应的锚点。
- **证据等级：A/B/C，强度。**
  - 事实：可核对的研究结论 + 引用。
  - 争论 / 重复失败：如有，必须写。
- **常见误传：** 流行说法 vs 原始出处实际说法。
- **操作步骤：** 3–5 步，可直接执行。
- **医学 / 科研用法：** 至少一个临床或科研学习场景。
```

## 规则

1. 文件名带版本号、不用下划线（README.md、LICENSE、CHANGELOG.md 除外），目录名用中文：`文档/`、`模板/`、`示例/`、`验证/`。
2. 每条新文献先加入 `验证/参考文献v1.0.json`（含 DOI、PMID、ISBN 或 URL），再重新生成或手动补 `文档/参考文献v1.0.md` 中带锚点的条目。
3. 效应量只写摘要或正文中核对过的数字；核对不到就不写数字。
4. 区分事实、关联与推测；C 级必须写“缺乏对照研究”。
5. 同步更新：`文档/方法总表v1.0.md` 一行、对应等级文件、必要时 `文档/学习流程v1.0.md` 和 `CHANGELOG.md`。
6. 只写自己的概括和链接，不粘贴原文、不转载原图；图用 Mermaid 自绘。
7. 提交前运行 `python3 验证/项目检查v1.0.py` 与 `python3 验证/引用核对v1.0.py --online`，全部通过再提交。
8. GitHub Actions 额度不足时，提交信息末尾加 `[skip ci]`。

## 粘贴给 Codex 的提示词

```text
你在维护公开仓库 TUANZIDING/learning-method-playbook（学习方法论手册）。请按仓库现有风格扩充方法，具体要求：

【任务】新增方法：<方法名，例如“生成效应 / 预测试 / 睡眠与记忆巩固 / 番茄工作法”>，判断应归入 A、B 还是 C 级。

【先读】README.md、文档/证据分级v1.0.md、文档/扩充指南v1.0.md、文档/A级方法v1.0.md（看一条完整条目的写法）、验证/参考文献v1.0.json。

【检索与核实】
1. 只用 PubMed、Crossref、出版社页面或作者主页等原始来源；不得编造任何引用、DOI、PMID、效应量。
2. 优先找：原始提出文献、最新元分析/系统综述、重复失败或争议研究、医学教育中的研究。
3. 每条文献用 Crossref（https://api.crossref.org/works/<DOI>）或 PubMed E-utilities 核对题名、年份、期刊；核对不到的不要写进正文。
4. 效应量只引用摘要或正文中确实出现的数字。

【写作】
1. 中文为主，结论先行；按 文档/扩充指南v1.0.md 的条目格式写：一句话、原始出处、证据等级（含“事实/争论”分行）、常见误传、操作步骤、医学/科研用法。
2. C 级方法必须写明“缺乏对照研究”；若某成分有研究支持，单独注明。
3. 只写自己的概括、书目信息和链接，不粘贴书籍或论文原文，不转载原图；需要图时用 Mermaid 自绘。
4. 文件名带版本号、不用下划线（README.md 等除外）；沿用中文目录 文档/ 模板/ 示例/ 验证/。

【同步修改】
- 验证/参考文献v1.0.json 增加新文献（字段与现有条目一致，check 填 doi/pmid/isbn/url）。
- 文档/参考文献v1.0.md 增加带 <a id="key"></a> 锚点的条目。
- 对应等级文件增加条目和开头汇总表的一行；文档/方法总表v1.0.md 增加一行；README.md 中的方法数量、文献数量徽章同步更新。
- 如果方法改变了流程，更新 文档/学习流程v1.0.md。
- CHANGELOG.md 写一条，版本号按语义化版本递增（新增方法为次版本号）。

【检查与提交】
1. 运行 python3 验证/项目检查v1.0.py 与 python3 验证/引用核对v1.0.py --online，全部通过；出现“??”的条目逐条人工复核后再继续。
2. 列出你改动的文件、新增文献清单（含 DOI/PMID）、以及你无法核实而没有写入的内容。
3. 整理成一次提交推送到 main，提交信息格式：“新增方法：<方法名>（<等级>）[skip ci]”。推送前先给我看改动摘要，等我确认。
```
