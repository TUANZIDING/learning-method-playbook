# 开源工具与资源 · Open-source tools and resources

<sub>星数、许可证和最近提交日期于 2026-10-27 通过 GitHub API 读取，之后会变化。**星数代表受欢迎程度，不代表学习效果的证据**；每个仓库都标了它服务于哪条方法，证据等级仍以 [方法总表](方法总表v1.0.md) 为准。本仓库只做链接和说明，不复制这些项目的代码或内容。</sub>

**一句话结论：** 必装两个——**Anki（开启 FSRS 调度）**负责提取 + 间隔，**Zotero** 负责文献；笔记网络在 Obsidian / Logseq / 思源中选一个；画图用 Mermaid 或 Excalidraw。其余按需。
